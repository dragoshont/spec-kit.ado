# Changelog

All notable changes to the "speckit-ado" extension will be documented in this file.

## [0.1.0] - 2025-10-30

### Added
- Initial release of Spec-Kit Azure DevOps Integration extension
- Command to sync spec-kit tasks with Azure DevOps work items
- Support for parsing Markdown-formatted spec-kit tasks
- Automatic creation of new work items in Azure DevOps
- Update existing work items when task details change
- Smart tagging system for tracking spec-kit tasks in Azure DevOps
- User story mapping from spec-kit to Azure DevOps
- Status synchronization (pending, in-progress, completed)
- Configuration settings for Azure DevOps connection
- Comprehensive documentation and examples

### Features
- Parse spec-kit tasks from Markdown files
- Connect to Azure DevOps using Personal Access Token
- Create and update work items via Azure DevOps REST API
- Query existing work items by tags
- Map task statuses to Azure DevOps states
- Progress notifications during synchronization
- Error handling and user-friendly error messages
